# Kerolos Fayez Portfolio

A responsive personal portfolio for Kerolos Fayez, a frontend developer. It presents skills, project work, background information, and contact options in a polished one-page experience.

## Highlights

- Responsive layouts for mobile, tablet, and desktop screens
- Persistent light and dark themes
- Smooth in-page navigation
- Animated skills showcase and project gallery
- Accessible navigation, keyboard focus styles, and reduced-motion support
- Optimized local images with Next.js

## Built With

- Next.js
- React
- TypeScript
- Tailwind CSS
- React Icons, Lucide, and React Typed

## Run Locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Quality Checks

```bash
npm run lint
npm run build
```

## Project Structure

```text
src/
├── app/          # App shell, global styles, and home page
├── Components/   # Reusable portfolio sections and UI

```
